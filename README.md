# Vibeception

A delightfully silly pun on "inception" - this is a vibe coding app that literally codes itself through AI assistance.

## What's the Point?

The core concept is beautifully recursive: every commit in this repository comes from code generated by this very script. We're not carefully crafting features or debugging line by line - instead, we're having conversations with Claude about what we want, and the AI writes the code that becomes the next version of the tool.

It's vibe coding all the way down. The script asks Claude to improve itself, Claude responds with new code, and that code becomes the next iteration. Pure vibes, pure inception.

## How It Works

`test.py` is a simple command-line interface for chatting with Claude (Anthropic's AI). You can:

- Send prompts directly to Claude
- Include context files (like existing code) to inform the conversation
- Get responses that you can use to evolve the codebase

## Usage

First, set your Anthropic API key:
```bash
export ANTHROPIC_API_KEY=your_api_key_here
```

Basic usage:
```bash
python3 test.py "Write a function that does something cool"
```

Include context files:
```bash
python3 test.py --context existing_code.py --context README.md "Improve this code"
```

Multiple context files are supported - just add more `--context` flags.

## Requirements

- Python 3
- `requests` library (`pip install requests`)
- An Anthropic API key
